# wize.be

Site de WIZE SRL : *Wisdom at Work. Well-being in Motion.*

Statique, trilingue (EN, FR, NL), hébergé gratuitement sur Azure Static Web Apps.

```bash
python3 _source/build.py          # régénère les pages depuis _source/content.py
python3 -m http.server 4321       # aperçu local sur http://localhost:4321
```

Push sur `main` = mise en ligne automatique. Détails : `CLAUDE.md`, `docs/`.
